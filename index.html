إظهار Изхар — Ясность
Нун с сукуном или танвин читается чётко перед горловыми буквами.
📌 Буквы изхара (6 горловых):
ءهعحغخ
{ حَاسِدٍ إِذَا ، مِنْ خَوْفٍ }
إدغام Идгам — Слияние
Нун сливается со следующей буквой.
🔊 С гунной (2 харакат) — يَنْمُو
ينمو
🔇 Без гунны — لر
لر
{ لَهَبٍ وَتَبَّ ، فَمَن يَعْمَلْ }
إقلاب Иклаб — Замена
Нун превращается в мим с гунной 2 харакат.
📌 Только перед буквой ب
{ بِذَنبِهِمْ ، أَنبِئْهُم }
إخفاء Ихфа — Скрытие
Нун скрывается с носовым звуком 2 харакат перед 15 буквами.
صِفْ ذَا ثَنَا كَمْ جَادَ شَخْصٌ قَدْ سَمَا
دُمْ طَيِّبًا زِدْ فِي تُقًى ضَعْ ظَالِمَا
{ نَارًا ذَاتَ ، مِن شَرٍّ }
قلقلة Калькаля — Вибрация
Взрывное произношение при сукуне.
📌 Буквы: قطبجد
قطبجد
{ قُلْ أَعُوذُ ، يَجْعَلْ ، يَدْخُلْ }
مدّ Мадд — Долгота
Удлинение гласных. Буквы мадда: ا و ي
Табии — 2 харакат
Муттасиль — 4–5
Мунфасиль — 2–4–6
Ариз — 2–4–6
Лязим — 6
{ الْعَالَمِينَ ، الْكَافِرُونَ }
Буква ر — Тафхим / Таркик
Тафхим (твёрдо): при фатхе или дамме
Таркик (мягко): при касре

ا ب ج ح خ ع غ ف ق ك م ه و ي
